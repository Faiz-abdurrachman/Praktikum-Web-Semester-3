🧩 Praktikum Pemrograman Web
📚 Deskripsi

Repositori ini berisi hasil praktikum mata kuliah Pemrograman Web yang mencakup berbagai topik terkait pengembangan aplikasi web modern, mulai dari struktur dasar HTML, styling menggunakan CSS, hingga pemrograman dinamis menggunakan JavaScript dan framework pendukung.

Tujuan dari praktikum ini adalah untuk mengembangkan kemampuan mahasiswa dalam membangun website yang interaktif, responsif, dan terintegrasi dengan teknologi web terkini.

🧠 Tujuan Pembelajaran

Memahami struktur dan elemen dasar pada HTML.

Menerapkan konsep desain dan layout dengan CSS.

Mengimplementasikan interaktivitas menggunakan JavaScript.

Mengenal konsep client–server serta integrasi API.

Membangun proyek web dengan pendekatan modern dan clean code.

🧑‍💻 Teknologi yang Digunakan

HTML5

CSS3 / Tailwind / Bootstrap

JavaScript (Vanilla / DOM Manipulation)

(Opsional: tambahkan framework jika ada, misal React, Node.js, PHP, dsb)
